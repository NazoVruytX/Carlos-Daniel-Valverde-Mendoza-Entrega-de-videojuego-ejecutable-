🎮 Proyecto: Videojuego de Plataformas 2D (Entrega Final)

Proyecto académico desarrollado en Unity (C#). Este repositorio contiene tanto el código fuente completo como el ejecutable final del juego. Implementa control de físicas, detección de colisiones con enemigos, gestión de audio y un menú principal funcional.

👨‍🏫 Instrucciones de Revisión para el Docente

Para facilitar la calificación, hemos dividido las instrucciones en dos opciones dependiendo de lo que desee revisar:

Opción 1: Probar el juego ejecutable (Revisión Rápida)

Si desea jugar y evaluar el producto final de forma directa:

Haga clic en el archivo Entrega_Final_Videojuego.zip que se encuentra arriba en la lista de archivos de este repositorio.

En la siguiente pantalla, haga clic en el botón de descarga (ícono de flecha hacia abajo a la derecha).

Una vez en su computadora, haga clic derecho sobre el archivo .zip y seleccione "Extraer todo...".

Abra la carpeta extraída y haga doble clic en el archivo .exe para iniciar el juego.

Opción 2: Revisar el código fuente en Unity (⚠️ IMPORTANTE)

Este proyecto utiliza Git LFS para gestionar los "sprites" y recursos gráficos pesados de manera profesional.

❌ Por favor, NO utilice el botón verde "Download ZIP" nativo de GitHub para descargar el código. Si lo hace, GitHub no descargará las imágenes de Git LFS, lo que provocará que el piso y otros gráficos desaparezcan (se vean blancos o transparentes) al abrirlo en Unity.

✅ La forma correcta: Para evaluar el código y el proyecto con los gráficos y físicas intactas, por favor clone este repositorio directamente usando su terminal (Git Bash):

git clone https://github.com/NazoVruytX/Carlos-Daniel-Valverde-Mendoza-Entrega-de-videojuego-ejecutable-.git
